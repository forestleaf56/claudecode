# Weekly App — Week of 2026-07-27

## Concept: **Untangle**

A minimalist planarity puzzle for touch. The screen shows a web of glowing nodes
connected by lines — and the lines cross each other in a tangled mess. Drag the
nodes around until **no two lines cross**. When the web is fully untangled, the
level is solved and a new, harder one appears.

One-finger, meditative, and endlessly generatable. Completely different genre from
last week's arcade game (Orbit Weaver). Warm amber/violet palette to distinguish it.

Why it fits: genuinely mobile-first (drag with a thumb), self-contained (no backend),
procedurally generated so it has infinite content, and it has real depth (crossing
detection + guaranteed-solvable level generation) — ambitious without a server.

## Tech choices
- Single self-contained `index.html` — HTML + CSS + JS + Canvas 2D. No backend.
- No Supabase / no Gemini API → **no `api/` folder**, no Vercel serverless setup.
  Deploy = open the file or drop it on any static host.
- Levels generated by placing N points on a circle (guaranteed untangleable), wiring
  edges, then scrambling positions — so every level is always solvable.
- Progress (level reached, best moves) saved via `localStorage`.
- Mobile-first: full-viewport responsive canvas, devicePixelRatio scaling, pointer
  (touch + mouse) dragging, no scrolling.
