# Web examples

Open any `.html` file and press **F5** (or ▶ Run) to see a **live preview** beside the editor.
Edit the code and the preview updates as you type.

| File | What it shows |
|---|---|
| `bouncing_balls.html` | Canvas animation with gravity — click to add balls |
| `todo_app.html` | A small app with forms, lists and DOM updates |
| `snake_game.html` | A complete game with keyboard and swipe controls |
| `analog_clock.html` | CSS transforms driven by JavaScript |
| `css_animations.html` | Keyframe animations and hover transitions |
| `calculator.html` | A grid layout calculator |
