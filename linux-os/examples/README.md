# Example programs

79 small programs in 18 languages, ready to run. Open any file and press **F5** or the ▶ **Run** button.

| Folder | Run with |
|---|---|
| `python/` | `python3 file.py` — real Python 3 when online |
| `javascript/`, `typescript/` | `node file.js`, `ts-node file.ts` |
| `c/`, `cpp/` | `gcc` / `g++`, then `./program` |
| `java/` | `java File.java` |
| `csharp/` | `csc` + `mono` |
| `go/`, `rust/` | `go run`, `rustc` |
| `kotlin/`, `swift/` | `kotlinc`, `swift` |
| `ruby/`, `php/`, `perl/`, `lua/` | `ruby`, `php`, `perl`, `lua` |
| `sql/` | `sqlite3 :memory: < file.sql` |
| `shell/` | `bash file.sh` |
| `web/` | Live preview |

Compiled languages use real compilers on an online build service. Offline, simple programs still run with the built-in lite runner.
Programs that read input (like `04_guess_the_number.py`, `07_read_input.c` and `Greeter.java`) ask for it in the terminal.
